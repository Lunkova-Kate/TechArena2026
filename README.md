# Строительство газопровода

Нужно укладывать трубы в траншею так, чтобы занимать как можно меньше места.

Длина каждой трубы - от 1 до 40 метров. Траншею можно увеличивать только кусками по 20 метров. Уже уложенные трубы двигать нельзя.
У каждой новой трубы есть свой `PID`: у первой трубы `PID = 1`, у второй `PID = 2` и так далее.

## Команды интерактора
Интерактор отправляет по одному целому числу:
- положительное число `L` - добавить трубу длины `L`;
- отрицательное число `-K` - удалить трубу с `PID = K`;
- `0` - закончить работу.

Всего может быть до `200 000` команд.

## Что нужно отвечать
Если пришла длина новой трубы, нужно вывести:

```text
N D
```

`N` - сколько раз нужно увеличить траншею на 20 метров.
`D` - координата начала трубы.

Например:
```text
1 0
```
Значит, нужно выкопать 20 метров и положить трубу с позиции 0.

Если пришла команда удаления `-K`, нужно вывести координату начала трубы с таким `PID`:

```text
D
```

На команду `0` ничего выводить не нужно.

После каждого ответа нужно сбрасывать буфер. С помощью flush

Входные команды:
```text

```

